# ConectaMaker — código-fonte do MVP

Projeto demonstrativo recriado em HTML, CSS e JavaScript puro.

## Executar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador. Para melhor experiência, use uma extensão de servidor local (por exemplo, Live Server).
3. Não há etapa de build nem dependências de backend.

## Estrutura
- `index.html`: estrutura e conteúdo das seções.
- `styles.css`: identidade visual e layout responsivo.
- `app.js`: filtros, busca, favoritos, modais e persistência local.
- `assets/conectamaker-logo.svg`: símbolo vetorial.

## Funcionalidades demonstrativas
- Projetos filtráveis por categoria e busca textual.
- Favoritos salvos em `localStorage`.
- Modal de detalhes dos projetos.
- Login demonstrativo (não autentica usuários).
- Registro local de interesse em participar.
- Seções de aprendizagem, necessidades, competências, espaços e ferramentas.

## Limitações
Esta é uma reconstrução funcional baseada na interface pública e nas especificações do MVP. Não é uma extração do repositório original nem inclui backend, API, autenticação real, pagamentos, geolocalização ou envio de dados. Os projetos e oportunidades são fictícios. Os dados ficam apenas no navegador utilizado.
